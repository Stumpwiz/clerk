LESSONS LEARNED:
================================================================================
- Task definition registration can be tricky - verify image tags immediately after registration
- Using --family flag with --cli-input-json can cause issues
- Nginx routing must explicitly list all API endpoint prefixes
- ECS Exec requires specific IAM permissions and may not always work
- Building Docker images in CloudShell works well when local Docker isn't available
- Database upload via S3 + one-time ECS task is reliable
- Always verify the actual running container image, not just the task definition
