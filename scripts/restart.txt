## Troubleshooting

### Can't connect to local services
1. Check Docker is running: `docker ps`
2. Check services are up: `docker-compose ps`
3. View logs: `docker-compose logs -f`

### CORS errors in production
1. Check current CORS config (see commands above)
2. Verify domain is in CORS_ORIGINS list
3. Wait 5-10 minutes after updating (service restart time)

### Database connection errors
1. Verify DATABASE_URL format includes `+psycopg2` and `?sslmode=require`
2. Check password is correct: `ClerkAdmin_2025!`
3. Test connection with psql (see command above)

### Production deployment fails
1. Check AWS credentials: `aws sts get-caller-identity`
2. Verify Docker is running: `docker --version`
3. Check ECR login: `aws ecr get-login-password --region us-east-1`
