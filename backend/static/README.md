# Static Files Directory

This directory contains static files used by the application, particularly for PDF generation.

## Logo File

Place the Residents Council logo file here:

- **Filename:** `residentCouncilLogoSmall.jpg`
- **Location:** `backend/static/residentCouncilLogoSmall.jpg`
- **Usage:** Referenced in LaTeX templates for welcome letter generation

The logo should be a JPG file suitable for inclusion in LaTeX documents. The original file can be found in the prototype
at `prototype/static/residentCouncilLogoSmall.jpg`.
